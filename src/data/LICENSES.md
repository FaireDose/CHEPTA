# Data licenses

CHEPTA's code is MIT-licensed. Some of the data in this folder comes from other
sources with their own terms, recorded in the `source` field of every entry.

Files and results that people create with CHEPTA (project files, flowsheets, CSV and Excel
exports, numbers, diagrams) belong to them; the licenses here cover CHEPTA's code and data,
not those files (see the README, License).

Every source is listed once in [`sources.json`](sources.json), with an id; parameter records
refer to it in `source_ids` (their text `source` stays). The table below is generated from
that file. Parameters fitted for CHEPTA (tier `fitted`, with `validation/python/`) are
MIT-licensed like the code; the data they were fitted to keeps the terms of its source.
Reference results in `validation/fixtures/` are computed with CHEPTA's Python reference
model (MIT).
