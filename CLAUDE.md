@AGENTS.md

Read the guide that fits the task before you start it (plain paths, not loaded at startup):

- Before adding or changing data (a component, a property record, a pair, a source): docs/DATA_RULES.md, in full.
- For a model choice, tests or numerical changes: docs/METHOD_SELECTION.md.
- For workbench views: docs/UI_GUIDE.md.

Combine them when a task overlaps. If a task grows into another kind (a UI change that touches a parameter record,
for example), read that guide before going on. The current working rules for sessions are in docs/HANDOVER.md.
