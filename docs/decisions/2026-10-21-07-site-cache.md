# 2026-10-21: the website after the logo change (a cached chepta.js)

After the logo and warnings pull request was merged, the maintainer saw the website without the logo and without the
workbench. The cause: the new page calls `CHEPTA.brandLogo()`, which only the new `chepta.js` has, and the browser kept
the older `chepta.js` from its cache (the site lets browsers keep it for 10 minutes). The call failed before the
workbench started.

Changed:
- the page starts the workbench first, and the logo after it, so a missing logo can never stop the workbench;
- the website workflow (`.github/workflows/pages.yml`) asks for `chepta.js?v=<commit>`, so a browser never pairs a new
  page with an older script;
- the line under the workbench, "Model predictions, not measurements. Every parameter shows its source in the
  interface.", is removed, by the maintainer's request.
