## What was built

- [proposal 0016](../../proposals/0016-wilson.md), status **Proposed**, with its implementation in the same pull
  request: the maintainer accepts it by merging.
- The model (`src/thermo/activity/wilson.js`, key `WILSON`): Λ_ij = exp(a_ij + b_ij / T), the equations of The ChemSep
  Book (2nd ed., eqs. 10.13-10.15) and of thermo's `Wilson`.
- ChemSep's Wilson set: 165 pairs, tier "databank", set "chemsep" (`chemsep_pairs.py --all --models WILSON`), taken as
  thermo ships it (a_ij = ln(V_j / V_i), b_ij = −A_ij / R).
- Wilson pairs of one's own (My data, project files, requests, `library.add`); Wilson in the Model group, the
  flowsheet's Method page and the column's method.
- Two liquids: the column's phases "VLL" are refused with Wilson; every result warns where a pair's NRTL (else UNIQUAC)
  set predicts two liquids at that temperature.

## Choices made in the pull request, for the maintainer to confirm

1. **Constant-volume form** (as ChemSep's parameters were fitted), not volumes from the density records.
2. **Warn, not refuse**, where another model predicts two liquids; refuse only an explicit two-liquid request.
3. **No Wilson fits to ThermoML data yet**: adding Wilson to `fit_parameters.py` refits and gates every generated pair
   and edits known-issues.json, larger than this item; it is proposal 0016, step 2.
4. **Ethanol + ethylene glycol**: ChemSep's Wilson set misses the open 1-atm data by 5.3 K on average (ChemSep's NRTL
   set by 6.2 K). The test records it; no known-issue note was added (the known-issue kinds are fixed by
   test/azeotropes.test.js). Add one now, or let the fits replace the set?
