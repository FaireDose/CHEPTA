# 2026-10-21: the CHEPTA logo

The maintainer asked for a simple, modern, professional wordmark and selected the
lowercase design with a blue initial c. It replaces the plain name in the website
header and the previous separate icon and name in the workbench toolbar.

One reusable SVG component (`src/ui/brand.js`, `CHEPTA.brandLogo()`) supplies both placements. The blue c stays blue
and the remaining letters inherit the surrounding text color, including on the dark toolbar and when the page follows
the system's dark theme. The paths are drawn as vectors from the selected image concept, with no font or external image
dependency.

The maintainer supplied the logo as a package (`chepta-logo-update.zip`, prepared from main at 42257b3). Its full files
were older than main (the Charts workspace had been merged since), so only its patch's logo changes were applied, by
hand, to the current files; `brand.js` is identical to the package's.
