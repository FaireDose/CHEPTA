# 2026-10-25: The CORE full-text search

## What the maintainer asked for

- "ok, i added CORE. what is next?" (the CORE key is a network secret of the environment, for `api.core.ac.uk`, under
  CORE's personal licence agreed on 2026-10-23). The next step agreed on 2026-10-23 was to ask CORE for every gap.

## What was done

- **The CORE queries were fixed** (`validation/python/fulltext_search.py`). CORE's query parser ignores a group that
  holds an AND inside an OR, so the first queries returned the same works for every property of a component (29 for
  each of solketal's). Now each property is one flat expression of single words, and each form of the component's name
  is its own query; the passages are then screened for the exact names and property words, as for the other indexes.
  - CORE answers 500 to a field name (`fullText:`) and finds nothing for a quoted phrase; its search address needs the
    trailing slash.
  - The requests are paced at one per 7 s (CORE allows 10 per minute), and a 429 waits as long as CORE asks.
  - CORE serves the text of each work with the answer, so most works are read without downloading a PDF.
  - A cached query whose file name was cut at 180 characters now carries a hash, so two queries never share a file.
    The OpenAlex queries of 2026-10-22 had no such collision (382 distinct names).
- **The search** (`validation/data/searches/2026-10-25-fulltext.json`):
  - 167 gaps of 51 components; CORE found works for 108;
  - 891 works returned (up to 20 per name form), 371 of them read;
  - 30 gaps had a passage with a name and the property together. Each passage was read.
- **Found, held for the maintainer: limonene's vapour pressure up to 101.4 kPa.**
  - Source: Gowda, MEng thesis, Stellenbosch University 2018 (open in SUNScholar), Table 8.12: 17 boiling temperatures
    of pure (R)-limonene, 40.0-101.4 kPa at 417.0-450.9 K, stated to ±0.32 K.
  - The values were read in CORE's text of the PDF; both servers refuse scripts, so the PDF is to be downloaded and
    every value checked. The file is `validation/data/searches/held/article_limonene_gowda2018.json`.
  - The set lies 2.0 % below CHEPTA's curve. Pooled, it misses by +1.38 % (stated 0.88 %), and Wu 2019 then by
    -2.49 % (stated 1.62 %), so the pooling rule stops (DATA_RULES section 3). With both misses accepted, the curve
    reaches 450.9 K and gives a normal boiling point of 450.47 K (other measured values 449.3-450.8 K).
  - The 449.65 K the thesis prints is Yaws' handbook's, not taken.
- **Read, nothing for the gaps:**
  - levoglucosan: Booth et al. 2011 (pressures over the crystal, and a sub-cooled liquid value derived from them);
    a 2025 thesis whose heat of vaporization its author says is distorted;
  - L-lactide's melting in a UFSC thesis (not CHEPTA's DL-lactide);
  - glycolic acid: the vendor's values in an SRNL report;
  - the other passages name the component as a reactant, product, solvent or ligand.
  - A new lead without a free copy: levoglucosan's liquid vapour pressure at 468-528 K, Epshtein et al.,
    Zh. Prikl. Khim. 1964.
- **Free copies:** `open_copy.py` no longer counts a CORE record without a download or a text as a copy. Such records are
  CORE's copy of the Crossref metadata. The paywalled articles carried over in the missing-properties list all had one,
  and no copy.
- **The list:** `docs/missing-properties/MISSING_PROPERTIES_2026-10-25.md`, with a CORE column for the search (`missing_properties.py`),
  and the line "No record changed" when an update only records a search.
