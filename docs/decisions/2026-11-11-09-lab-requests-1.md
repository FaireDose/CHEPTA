## 2. `thermo.sets: "default"`

- **Cause.** `CHEPTA.run` with `sets: "default"` (the form CHEPTA's own record
  `validation/data/columns/B2-chemsep-benzene-toluene.json` writes) reached `normalizeFlowsheet`, which spread the
  string into `{ "0": "d", ... }`; the pair check then said `sets: "0" is not a pair`.
- **Choice.** The interface contract says `sets` is an object `{ "a+b": "set name" }` and the authoring-contract test
  lists `sets` among the thermo keys without a string form. CHEPTA's own record must be valid input, so `"default"` (and
  nothing) now means the default set of every pair, in `library.selection`, in the flowsheet's `thermo` and in a
  column's `method`. Any other non-object is refused with the key and the form:
  `flowsheet.thermo.sets must be an object such as { "acetone+chloroform": "chemsep" }, or "default" for the default set
  of every pair (got "chemsep")` (`setsInput` in `src/thermo/library.js`).

## 5. Source ids of the MHV1 sets

Checked every set of `src/data/mhv1.json` (30 sets: 24 fitted to ThermoML files, 6 to IAPWS G7-04 Henry constants)
against the data files its fit used (`source.data`, written by `validation/fit_mhv1_high_pressure.mjs`, which derives
the ids from the files with `sourceIds(r.files)`):

- **No id is wrong, and no correction was made.** Every id has a data file of its own pair among the fit's files, and
  every file of the pair has its id. The fit script is the source of truth; `make_sources.py` was not needed.
- **Why the ids look wrong.** A source id is named after the first file of its article. `pokki2018-furfural-gvl` is
  Pokki et al. 2018 (J. Chem. Eng. Data 63, 4381, doi 10.1021/acs.jced.8b00451), whose ThermoML record also holds a
  binary CO2 + water set (PureOrMixtureData 5, compounds 4 and 3, read 2026-11-12 in the record at
  trc.nist.gov/ThermoML/10.1021/acs.jced.8b00451.xml). Same for `wu2019-carbon-dioxide-methanol` on H2 and CO +
  methanol (Wu et al. 2019 measured CO and H2 in methanol; the id carries its CO2 file's name) and
  `schuler2012-carbon-dioxide-methanol` on CO2 + water.
- **Test.** `test/mhv1-sources.test.js`: every MHV1 set's ids exist, its data files are all of its own pair, each id
  has a file of this pair among them, and each file has an id.
