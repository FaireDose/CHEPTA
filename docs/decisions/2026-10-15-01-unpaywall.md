# 2026-10-15: legal free copies of paywalled articles (Unpaywall)

- **Asked:** "are you able to add for yourself this extension? i see it looks more in depth for free access for papers
  behind paywall: unpaywall extension"; then, for the contact address the Unpaywall API asks for, the project's domain
  address: "ok add" (info@cheptasim.org).
- **What Unpaywall is:** the database behind the browser extension (OurResearch). For a DOI it lists the copies anyone
  may read for free and legally: the publisher's open-access version, or an accepted or submitted manuscript in a
  repository. It does not bypass paywalls, so a copy it lists is an open source under AGENTS.md rule 1. An assistant
  cannot install a browser extension, but the same database is reachable through its API.
- **Added:**
  - `validation/python/open_copy.py`: the best legal free copy of each DOI (link, version, host, licence), cached per
    DOI; the contact address is info@cheptasim.org (`CHEPTA_CONTACT_EMAIL` overrides it).
  - `gap_report.py --open-copies`: for each component of a batch, the articles behind its ThermoML values with their
    free copies.
  - `docs/DATA_RULES.md`, section 1: before an article is set aside as paywalled, it is looked up; a copy found is cited
    with the published article, the link and its version, and the numbers are checked in that copy.
- **Limit:** Unpaywall does not know every free copy. The NIST reprints of J. Phys. Chem. Ref. Data (Ruzicka and
  Domalski 1993) are free but listed as closed, so "no copy found" is not "no open data" by itself. On the
  gamma-valerolactone articles of the ThermoML Archive (eleven, J. Chem. Eng. Data, J. Chem. Thermodyn., Fluid Phase
  Equilib.) it found no free copy; the archive's values stay open regardless.
