# 2026-10-29-02: Proposal 0015, milestone M0: the contracts and the request path

The maintainer, 2026-10-29: "go" (start M0, after accepting proposal 0015).

## What M0 is

The contracts of proposal 0015, section 9, written down in ARCHITECTURE.md ("The request path and the contracts"),
with the main branch green: what is not built refuses explicitly, and its test checks the refusal.

- **The request path** (contract 6): `CHEPTA.run(request)` and `CHEPTA.capabilities()` in `src/api/dispatcher.js`,
  over the existing functions (`runFlowsheet`, `flowsheetDocStatus`, `checkProject`, the component records). Results
  carry an outcome, the error's fields or blocks, the checks by group, the qualifications (each pair's set and tier),
  and the reproduction data (version, method, parameter sets, hashes of the input, the records used and the user's
  data). The Flowsheet workspace now solves through it.
- **The execution envelope** (contract 7, `src/runtime/envelope.js`): run id, input hash, limits (`time_ms`), status,
  cancellation, and a gate that discards a late result. Runs are on the caller's thread for now: the worker that can
  stop a running calculation comes with M1 (W9), and the text says so.
- **Unit v2** (contract 2): `runUnit` passes on a block's `profile`, `warnings` (codes DRY_STAGE, FLOODING, WEEPING) and
  `method`; existing blocks return none of them and are unchanged.
- **Refusing until built:** the column engine (`src/units/columns/engine.js`, M1 and M2a), the sizing layer
  (`src/sizing/sizing.js`, M1 to M3), and the `solve_column` capability (listed as unsupported).
- **Project format 6** comes with the first new block (M1): a project is written in the lowest format that holds it, so
  a format without a new block would change nothing.
- **Small engine changes:** `flowsheetRun` in `src/flowsheet/document.js` returns the property package with the result
  (`runFlowsheet` is unchanged); each loop of a solved flowsheet now also reports its last tear residual and the
  tolerance.

## How it was checked

- `test/api.test.js`: the example `examples/heater-flash.chepta.json` (ethanol and water, NRTL, a heater and an
  adiabatic drum) through the whole path: project check, request, the same numbers as `runFlowsheet`, balances, the
  reproduction data, saved by the workbench and reopened with the same result. Also: a missing specification names
  its block; an unknown key names its field; benzene + glycerol with NRTL stays "missing data" with no value; the
  column is refused; a bug is the outcome "error"; the hash against the published FNV-1a test values; the envelope's
  limits and its gate; Unit v2.
- In Chromium (the preview build): the example loaded in the workbench solves (the drum at 81.85 °C), with no page
  errors, and saved and reopened shows the same page (only the solve time differs).
- `npm test`: all tests pass.
